📋 Table Descriptions

Table Purpose Relationships
search_history Legacy search logging — powers Popular Searches aggregation Standalone
user_activity Structured query record with response time and forecast outcome → activity, → forecast_result
place Named geographic entity (point, path, or area) — deduplicated by name → location
location Individual lat/lon coordinate point belonging to a place → forecast_result, → actual_result
activity Detected outdoor activity with rain tolerance threshold ← user_activity
forecast_result AI prediction per query per location point with confidence score ← user_activity, ← location
actual_result Real-world observed rainfall from NEA for forecast accuracy tracking ← location
geocode_cache L2 shared cache — Nominatim geocoding results (cross-worker, persistent) Standalone
overpass_cache L2 shared cache — OSM path data as JSON (cross-worker, persistent) Standalone
