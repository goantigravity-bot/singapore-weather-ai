Data Quality Observations

⚠️ Negative Rainfall Predictions
Some forecast_result records show negative rainfall_mm values (e.g. -6.34mm). The model output should be clamped to max(0, predicted) to prevent nonsensical predictions appearing in accuracy calculations.
⚠️ Timezone Mismatch (Fixed)
NEA API returns observation_time with +08:00 timezone offset, but SQLite julianday() cannot parse it. The accuracy-backfill-test.py normalizes timestamps. The live actual_collector.py still needs the same fix.
