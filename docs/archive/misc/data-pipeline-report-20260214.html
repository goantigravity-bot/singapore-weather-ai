Strategy: Rain-Day Data for Training

The current model trains on all available dates uniformly. However, most days in Singapore have extended dry periods, which creates a data imbalance — the model learns to predict "no rain" very well but performs poorly on actual rainy events.

Current Problem

Metric Value Notes
Total Training Days 193 Oct 2025 – Jan 2026
Estimated Rain Days ~100–120 Singapore averages ~167 rain days/year
Estimated Dry Days ~70–90 Contributing minimal rainfall signal
Model Bias Toward 0mm Dry-day dominance suppresses wet predictions
Negative Predictions Observed No ReLU/clamping on rainfall output head

Proposed Strategy: Rain-Day Prioritized Training

Step 1: Data Classification

Classify each training day based on total rainfall recorded across all stations:

Category Criteria Training Weight
🌧️ Heavy Rain Day >= 20mm total in any station 3x oversampling
🌦️ Moderate Rain Day 1mm – 20mm total 2x oversampling
☀️ Dry Day < 1mm total 1x (baseline)

Step 2: Weighted Sampling in DataLoader

Instead of discarding dry days, use a WeightedRandomSampler in PyTorch to oversample rain events:

# Assign weights based on daily rainfall classification
sample_weights = []
for sample in dataset:
    if sample.daily_rainfall >= 20:
        sample_weights.append(3.0)  # Heavy rain
    elif sample.daily_rainfall >= 1:
        sample_weights.append(2.0)  # Moderate
    else:
        sample_weights.append(1.0)  # Dry

sampler = WeightedRandomSampler(sample_weights, num_samples=len(dataset))

Step 3: Loss Function Enhancement

Apply asymmetric loss to penalize underestimation of rainfall more heavily than overestimation:

# Asymmetric MSE: higher penalty for under-predicting rain
def rain_aware_loss(pred, target, alpha=2.0):
    error = pred - target
    # Under-prediction (pred < target) gets alpha x penalty
    weights = torch.where(error < 0, alpha, 1.0)
    return (weights * error ** 2).mean()

Step 4: Output Constraint

Enforce physical constraints on the model output:

# In predict.py — clamp rainfall to non-negative
predictions['rainfall'] = max(0.0, raw_prediction['rainfall'])
