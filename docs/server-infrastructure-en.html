Data Flow

sequenceDiagram participant JAXA participant DL as Download Server participant S3 participant TR as Training Server participant API as API Server Note over DL: Every 10 minutes JAXA->>DL: Himawari .nc (FTP) DL->>DL: Crop Singapore region → .npy DL->>S3: Upload .nc + .npy Note over DL: Every 5 minutes DL->>DL: Collect data.gov.sg API DL->>S3: Upload sensor JSON Note over TR: On-demand / Manual trigger S3->>TR: Download .nc/.npy + JSON TR->>TR: Preprocess + Train (100 epochs/batch) TR->>S3: Upload latest.pth Note over API: Every 5 minutes S3->>API: Sync .npy + model + CSV API->>API: Multi-modal inference
