职责: 提供天气预测 REST API + 前端静态文件服务。

关键文件: | File | Purpose | |------|---------| | api.py | FastAPI 主服务 — 预测、搜索、监控、数据同步 | | predict.py | 推理逻辑 — 集成预测 + Delaunay 三角化 + 云层分析 | | weather_fusion_model.py | 模型定义 (与 training 共用) | | weather_dataset.py | Dataset 工具函数 (latlon2xy) | | db.py | SQLite 数据层 — 缓存、用户活动、预测记录 | | smart_query.py | NLU 自然语言查询解析 | | geocoding.py | 地理编码 (Nominatim + OneMap) | | monitor_api.py | 监控仪表盘 API | | actual_collector.py | 实际天气数据采集（对比预测准确性） | | perf-test.py | 性能测试脚本 |

├── history/training_history.json # 训练历史记录
└── archived/                    # 已归档数据

Data Flow

sequenceDiagram participant JAXA participant DL as Download Server participant S3 participant TR as Training Server participant API as API Server Note over DL: 每10分钟 JAXA->>DL: Himawari .nc (FTP) DL->>DL: 裁剪新加坡区域 → .npy DL->>S3: 上传 .nc + .npy Note over DL: 每5分钟 DL->>DL: 采集 data.gov.sg API DL->>S3: 上传传感器 JSON Note over TR: 按需/手动触发 S3->>TR: 下载 .nc/.npy + JSON TR->>TR: 预处理 + 训练 (100 epochs/batch) TR->>S3: 上传 latest.pth Note over API: 每5分钟 S3->>API: 同步 .npy + model + CSV API->>API: 多模态推理
